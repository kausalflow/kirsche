    Lightkone from the command line¤

    Kirsche is the command line for Lightkone. It reads and writes the same files as the web app, wherever your library lives, so you can switch between the browser, the terminal and a notebook freely. kirsche and lightkone are the same command.

    Set up¤

    pipx install kirsche          # or pip install kirsche

    The quickest way to point it at your library is a settings backup from the web app: Settings → Backup → Export settings. Then

    kirsche login --from-backup lightkone-settings-2026-11-10.json

    Only where the library lives (and an OpenAlex key, if you set one) is kept, in ~/.config/kirsche/config.json, readable by you only. An encrypted backup asks for its passphrase (install kirsche[crypto] for that).

    Or set it up by hand:

    kirsche login --provider s3       # endpoint, bucket, region, folder, access key, secret
kirsche login --provider github   # owner/name, a fine-grained token, branch
kirsche login lab --provider folder --set path=~/papers

    Several libraries can be kept under names: kirsche libraries, kirsche use lab, or -L lab on any command. --dir PATH (or LIGHTKONE_DIR) uses a folder directly, for example a clone of the library's GitHub repository.

    A library kept only in a browser can't be reached from the command line; move it to a bucket or repository first.

    Find and read¤

    kirsche ls                                   # newest first
kirsche ls gravitational lensing             # best match first
kirsche ls author:einstein year:1915-1920 -o bib
kirsche ls in:Physics/QFT is:starred has:pdf
kirsche show Hinton2012-in
kirsche text Hinton2012-in | grep -i dropout # once the reader has extracted it
kirsche highlights Hinton2012-in -o markdown
kirsche pdf Hinton2012-in --open

    The search syntax is the app's: words anywhere, tag:"a b", author:, year:2019 or year:2015-2020, in:Folder/Sub, is:starred|recent|trash, has:pdf|abstract|arxiv|notes and no: for the opposite.

    Open in the browser¤

    kirsche web                          # the Lightkone app
kirsche open Hinton2012-in           # the paper's details
kirsche open Hinton2012-in -p 3      # its reader at page 3

    --url (or LIGHTKONE_URL) points at another Lightkone, such as your own deployment or staging. The browser uses the library set up in its own Lightkone Settings.

    Add and organise¤

    kirsche add 2106.09685 10.1103/PhysRevLett.116.061102 -t lensing -f Physics/GR
kirsche import paperpile.bib --dry-run
kirsche tag Hinton2012-in -a dropout -r todo
kirsche tag -q 'author:einstein year:1915' -a classics
kirsche folder -q tag:lensing -a Physics/GR
kirsche note Hinton2012-in "Compare with DropConnect."
kirsche star Hinton2012-in
kirsche trash Hinton2012-in              # --restore to take it back
kirsche attach Hinton2012-in ~/Downloads/1207.0580.pdf

    Each change is saved straight away. Before writing, the library is read again and anything saved elsewhere since (in the app, by Claude through MCP, or by another run) is merged in field by field, the way the app does it.

    Export¤

    kirsche export -o library.bib
kirsche export in:Thesis -o thesis.bib
kirsche export tag:lensing -f csv -o lensing.csv

    The citation map¤

    kirsche map                        # citation-map.html for the whole library
kirsche map in:Thesis --open
kirsche map tag:lensing -o lensing.json --linked-only
kirsche missing in:Thesis --min 3  # what your thesis papers keep citing that you lack
kirsche missing --add -t to-read

    References come from OpenAlex and are kept in lightkone/citations.json, shared with the web app's Citation map, so each paper is looked up once. OpenAlex's free budget is per network; for a budget of your own pass --openalex-key or set OPENALEX_API_KEY. The page draws papers across by year and up by how often they are cited, in bands by folder, as Kirsche always did; tap a paper to see its links. The JSON has nodes and edges for networkx, Gephi or D3.

    In Python¤

    from kirsche.lightkone import Library, S3Storage

lib = Library(S3Storage(endpoint="https://<account>.r2.cloudflarestorage.com", bucket="papers",
                        access_key_id="...", secret_access_key="...")).load()
recent = lib.search("year:2024-2026 has:pdf", sort="year")
df = lib.to_dataframe(recent, columns=["key", "title", "year", "tags"])

    Papers are plain dicts in the shape of Lightkone's Paper record, so fields this version does not know survive a save.
